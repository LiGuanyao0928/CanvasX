能帮你做什么

📋

作业看板

按紧急程度分类显示所有作业，说明和附件直接展开在卡片里，不用再点进 Canvas 网页。

📁

课程资料

Canvas Modules 里的讲义/PPT 自动下载到本地，网盘式浏览 + 全文搜索。

📊

成绩计算

按分组权重算当前成绩，还能试算"这门作业考多少分，总成绩会变成多少"。

🗓️

课程表

手动录入一次，支持隔周课和阅读周，按周切换显示实际日期，课程名对接真实 Canvas 课程。

🔔

手机推送

ntfy / Discord / 苹果快捷指令，自动同步时间点像闹钟一样自己设。

📅

日历同步

Mac 自动写进系统日历；Windows/Linux 生成标准 .ics，导入 Outlook / Google 日历都行。

常见问题

我的 Canvas 账号信息安全吗？

CanvasX 完全在你自己电脑上运行，账号 Token 和作业数据只存在本机，不会上传到除 Canvas 官方以外的任何服务器，源码也是公开的，可以自己核实。

Mac 上提示"无法验证开发者"打不开怎么办？

去"系统设置 → 隐私与安全性"，找到提示信息，点"仍要打开"即可。这是因为 App 没有用付费的 Apple 开发者证书签名，不影响正常使用。

生成不了 Canvas Access Token 怎么办？

通常是学校 Canvas 管理员关闭了学生自主生成 Token 的权限，需要联系任课老师或学校 IT/教务开启这项权限，详见仓库 README 的常见问题部分。

Windows 客户端稳定吗？

这部分是较新加入的功能，如果遇到问题欢迎在 GitHub 仓库提 Issue，或者直接联系作者反馈。
