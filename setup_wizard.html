连接你的 Canvas 账号

登录一次，之后每天自动帮你追作业、算成绩、整理课程资料

在 Canvas 网页里，进入「账户 → 设置」，拉到最下面点「+新建访问令牌」，把生成的 Token 粘贴到下面。网址就是你平时登录 Canvas 用的那个网址（不用带后面的路径）。

生成不了 / 找不到 Token？

这通常是学校 Canvas 管理员关掉了学生自主生成 Token 的权限，不是你操作有问题。解决办法：找任课老师或学校 IT/教务，请他们在 Canvas 管理后台给你开启「用户自主生成访问令牌」的权限。目前没有不需要 Token 就能用的替代方案——Canvas 官方的应用授权（OAuth）流程需要学校管理员审批，普通学生个人没法自己申请。

这个 App 完全在你自己电脑上运行：Canvas 网址和 Token 只保存在本机，不会上传到 Canvas 官方以外的任何服务器；开启手机推送的话，作业标题会发给你自己选的推送服务。这是同学做的个人小工具，不是学校或 Canvas 官方产品。

⚠️ 不是你自己的私人电脑（比如图书馆/机房的公用电脑）？取消勾选——退出 App 时会自动清除这台电脑上的登录信息，不会留给下一个用的人看到。

选择要追踪的课程
